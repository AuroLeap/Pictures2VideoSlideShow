## High-level flow (Rust engine)

```
config (TOML)               media scan (rayon)            per clip
  Config ──────────────►  MediaLoader.scan_and_index ──►  FrameSource
                              │  image dims (image)          ├─ ImageFrameSource: ClipPlan → crop/resize/rotate (rayon)
                              │  video meta  (ffprobe)        └─ VideoFrameSource: VideoFrameReader (ffmpeg decode)
                              ▼                                        │
                          Album (ordered)                             ▼
                                                          CrossfadeMixer (dissolve tail→head,
                                                          fade in first / out last)
                                                                       │ raw rgb24
                                                                       ▼
                                                          FfmpegEncoder (libx264, yuv420p) → <name>.mp4
```

## Module responsibilities

| Module | Responsibility |
|---|---|
| `src/config` | Load/validate TOML/JSON config (`OutputDef`, Ken Burns params) |
| `src/media` | Parallel scan, classify, dimensions/duration, ignore patterns |
| `src/transform` | `ClipPlan`: Ken Burns window + rotation math (deterministic) |
| `src/image` | `FrameRenderer`: pre-scale once, per-frame crop/resize/rotate |
| `src/video` | `VideoFrameReader`: stream decoded frames from ffmpeg |
| `src/ffmpeg` | `FfmpegEncoder`: stream raw rgb24 → H.264 MP4 |
| `src/pipeline` | `FrameSource` abstraction + `CrossfadeMixer` orchestration |
| `src/util` | dirs, progress |
